## 发现与修正

第一次执行器调用被端口预检查拒绝：刚退出的独立 llama-server 连接处于 TIME_WAIT，普通 bind 错判端口占用。修正 Linux 检查的 SO_REUSEADDR 语义，保留对真实监听服务的拒绝，未修改进程所有权和 GPU 释放机制。

新增回归测试实际建立 TCP 连接并由服务侧先关闭，证明普通 bind 失败、修正检查成功，同时验证活跃监听仍被拒绝。云端 Linux 7 项语言模块测试全部通过；本地 Windows 6 项通过，Linux socket 测试跳过。修正源文件在云端隔离 source 目录运行，未覆盖已安装的 0.12.1 发布目录；三个 GPU 执行器任务随后连续通过。

## 输出观察与范围

所有 9 次模型调用正常 stop，三项执行器任务均产生非空结果。中文示例保留森林、溪流、鸟鸣；图片改写保留蓝色玻璃杯和无文字；视频改写保留固定镜头、5 秒和旋转动作。

这不是提示词质量满分验收：一次视频改写超出 80–100 英文词目标，且没有显式保留“无音乐、无对白”，中文示例也出现不自然的“雾霂”用词。视频基准使用简短测试规则，没有加载 H3 官方 Skill，也没有调用 H3 生成视频。正式提示词优化仍需约束保留与输出质量评测。

结论：该公共 Q5_K_M 文件可在受测 5090 / llama.cpp 组合运行，适合作为后续模型接入候选。未自动替换 Worker 原有模型配置，未完成此模型的 Server/Studio 全链路验收。测试后释放进程与显存，停止测试管理服务，并通过平台 API 确认实例状态为 Stopped。
